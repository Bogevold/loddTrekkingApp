# Plan: Ticket Name Registration & localStorage Persistence

## Context
The lottery app currently only shows ticket numbers. Users want to register buyer names on individual tickets to track sales over time, persisted in the browser's localStorage. When drawing winners, names should be displayed instead of just numbers.

## Files to modify
- `app/index.html` — Add registration UI elements
- `app/trekking.js` — Add name registration logic, localStorage persistence, update drawing/display
- `app/loddTrekking.css` — Style the registration UI and sold-ticket indicators
- `VERSION` — Bump from 1.0.2 to 1.1.0 (new feature = minor bump)

## Implementation Steps

### 1. Add localStorage helper functions (`trekking.js`)
- `saveNames()` — saves the name map (`{ticketNumber: name}`) to `localStorage` using a key based on the current ticket count (e.g. `loddNavn_35`)
- `loadNames()` — loads the name map from `localStorage` for the current ticket count
- `clearNames()` — clears stored names for the current ticket count
- A global variable `varNavn = {}` to hold the current name mapping in memory

### 2. Make tickets clickable for name registration (`trekking.js`)
- In `creDivLodd()`, add a click handler on each ticket div
- On click, prompt the user for a name (using `window.prompt`)
- Store the name in `varNavn` and call `saveNames()`
- Update the ticket div to show a visual indicator that it's sold (e.g. different background color and a tooltip with the name)
- If a name is already registered, pre-fill the prompt so users can edit or clear it

### 3. Update ticket display to reflect sold status
- In `creDivLodd()`, after creating tickets, call `loadNames()` and apply sold styling to tickets that have names
- Add CSS class `.solgt` (sold) with a distinct background color
- Show the name as the ticket text (truncated if long) or as a tooltip, keeping the number visible

### 4. Update winner display to show names (`trekking.js`)
- In `velgLodd()`, where the winner text is composed (line ~113), check if the winning ticket number has a registered name in `varNavn`
- Change the text from `"Vinner nr X ble lodd nr: Y"` to `"Vinner nr X: Navn (lodd nr Y)"` when a name exists

### 5. Add "Clear names" button (`index.html`)
- Add a button in the settings panel to clear all registered names for the current ticket count
- Wire it to `clearNames()` which removes from localStorage and refreshes the display

### 6. Handle ticket count changes
- When the user changes "Antall lodd", `fnyBeregn()` already calls `creDivLodd()`
- Ensure `loadNames()` is called so names are restored if the user switches back to a previously used ticket count

### 7. CSS additions (`loddTrekking.css`)
- `.solgt` class: light green background to indicate sold tickets
- `.lodd` cursor: pointer to indicate clickability

## localStorage schema
```
Key: "loddNavn_<antallLodd>"
Value: JSON string of { "1": "Ola", "5": "Kari", ... }
```

Using the ticket count in the key allows independent name sets for different raffle sizes.

### 8. Bump version
- This is a new feature (minor bump): update `VERSION` file from `1.0.2` to `1.1.0`
- Update the version string in `app/index.html` from `v1.0.2` to `v1.1.0`

### 9. Build and deploy
- Run `make upgrade` which will: build the Docker image, push to registry (`homelab:30500`), create git tag, and upgrade the Helm deployment on K3s
